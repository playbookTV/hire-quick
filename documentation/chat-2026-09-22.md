# Gifted Chat integration — 22 September 2026

This is the chat portion of OVA-172. It does not close the broader list-pagination ticket, OVA-99, or the R2 upload-finalization/deletion tickets.

## Implemented

- Gifted Chat 3.4.0 replaces the custom ScrollView message list and composer. The adapter preserves booking context, locked conversations, contact-sharing notices, private images, read indicators, and explicit retries.
- History opens with the latest 50 messages. Older history loads on demand. Foreground/focused polling requests only messages after the latest server cursor and bounded read receipts; missed updates drain in batches of at most 50, with at most ten batches per refresh. Mobile Socket.IO and background push remain OVA-164 work.
- Each outgoing message has a UUID retained across retries. REST and Socket.IO share the duplicate check. An altered payload, conversation, or sender cannot reuse an existing ID. Per-conversation append locks and strictly increasing timestamps prevent concurrent commits from falling behind a synchronization cursor.
- Up to eight unconfirmed outgoing messages are saved in device SecureStore, scoped by user and booking. Recovery never sends automatically. Confirmed IDs merge with pending entries, including after a lost acknowledgement. Requests time out after 15 seconds and retain their original ID for retry. Session changes and unmounts fence late responses.
- The shared chunked keychain helper accepts a separate chat namespace and does not split Unicode surrogate pairs. Existing checkout storage keeps its original namespace.
- Legacy history responses retain their array shape but are capped at 100 messages. Read-receipt cursors must belong to the conversation and use the database's timestamp/ID ordering.

## Rollout and remaining work

Deploy the API before distributing the mobile build; the updated app requires `/messages/page`. No schema changes are required by this slice. The current conversation index remains; a composite history index and large-history query profiling belong to the remaining OVA-172 work.

The package is pinned to the original Gifted Chat approved in this task. Its current upstream README marks it as maintenance-only and points to a successor. Our application-specific state and transport live outside the UI package, so a future switch does not require replacing the messaging backend.

The chat slice originally preserved the existing direct-to-S3/R2 upload flow. The subsequent [upload work](uploads-2026-09-22.md) adds finalization and durable cleanup and requires an API/database/mobile rollout together. Broader erasure inventory and retention holds remain OVA-146/OVA-162. Voice playback/recording remains unimplemented as before.

Native keyboard behavior, loading older history while scrolled, dark mode, background/foreground transitions, and real device restart recovery still need device interaction checks. This machine's active developer tools do not provide `simctl`. A successful Expo export is bundle validation, not a device-test result.
